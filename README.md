# Post template

This branch exists as an orphan branch, so I can quickly create branches for larger code samples for my blog.

For future me, to get started

```sh
# Checkout this template branch
$ cd path/to/this/blog
$ git checkout post-template

# Create the orphan branch
$ git checkout --orphan post-YYYY-MM-SLUG

# Commit the initial set of files as an initial commit
$ git add .
$ git commit -am "Initial commit"
```
